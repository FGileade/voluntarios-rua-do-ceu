# Voluntários Rua do Céu

Página independente para cadastrar voluntários ativos no Firebase do projeto Rua do Céu.

Os dados são inseridos exclusivamente na coleção `voluntariosAtivos`. O projeto não lê, altera ou exclui coleções existentes.

Campos: nome completo, função (Monitor, Líder de Equipe ou Administrador), telefone/WhatsApp e e-mail.
